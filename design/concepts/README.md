# Zf 传图：三种界面方向

这些是供选型的概念图，由内置 `imagegen` 以当前 0.3.0 界面截图为功能参考生成，并非应用截图。照片、相机状态、容量与 EXIF 信息都是示意；实现时只显示应用实际取得的数据。

| 方案 | 生成提示词的设计重点 | 交互与实现要点 |
| --- | --- | --- |
| [A 取景器](a-viewfinder.png) | 哑光石墨黑、少量尼康黄、锐利字体、细分隔线与选中照片的角标；双列照片网格。 | 与现有网格最接近；连接条缩小，照片面积增加。 |
| [B 影像画廊](b-editorial-gallery.png) | 黑黄摄影编排、首页一张跨列大图、其余双列接触表、文字式筛选与小型勾选角标。 | 浏览最突出；跨列照片需要保持滑动选中的连续顺序。示意图中的 EXIF 参数不代表现有应用已读取。 |
| [C 快速选片](c-expressive-grid.png) | 大面积黄色顶栏、黑色三列高密度照片网格、集中式底部操作栏。 | 适合从大量照片快速批选；顶部示意存储容量需要真实数据或改成已有的连接信息。 |

三个方向均保留相机连接、日期与格式筛选、长按滑动批选、选中数量、原图下载。黑黄主色沿用当前应用，不使用尼康官方商标图形。

## 已实现的混合方向

用户选择 A 的上半部分与 C 的三列预览、选中标记。`0.3.1-zf-lab` 已实现，虚拟机截图见 [hybrid-v031-emulator.png](hybrid-v031-emulator.png)。截图显示离线缓存，因此未缓存缩略图的照片用文件格式和文件名表示；实际相机缩略图会填入相同的方形位置。虚拟机实测长按滑动跨行选择 6 张、序号 1–6 以及反向取消。

`0.3.2-zf-lab` 将模式设置移到连接按钮旁，断开状态见 [preconnect-mode-v032.png](preconnect-mode-v032.png)。
