# Zf 传图图标方案（待选择）

使用内置 imagegen 生成的概念预览；当前 APK 尚未替换启动图标。三款共用近黑色 `#111310` 与暖黄色 `#F5D547`，均要求居中、保留 Android 自适应图标安全边距、无文字或尼康商标。

- **A · 相机传输**：简化相机机身，镜头内部以黑色负形构成向下传输箭头。强调用途一眼可懂。
- **B · 光圈传输**：粗线条快门叶片围绕中央负形箭头。强调摄影属性与动态感。
- **C · 几何 Z**：两个照片画框角连接成 Z 形路径，在末端接向下箭头。强调独立品牌感。

这三张 PNG 仅供视觉选型。选定后应按所选方向绘制可缩放的 Android 自适应图标前景，并在小尺寸、圆形和方形裁切下复核。

## 第二轮与定稿

基于用户选择的 C 方案，进一步放大 Z 的主体，形成 `Z1-bold-z.png`、`Z2-outline-z.png`、`Z3-card-z.png` 三款。用户选中了 Z1 的粗体 Z 方向。

- `Z-final-refined.png`：按所选图精修的视觉稿，调整了 Z 的比例、山形留白与箭头连接。
- `Z-final-vector.svg`：根据精修稿绘制的平面矢量母版。Android 使用同一轮廓的 `ic_launcher_foreground.xml`；山形是透明镂空，以支持系统主题图标。
- 自适应图标的背景为 `#111310`，前景为 `#F5D547`，主体留在 108dp 画布的中心安全区域。

本地 `0.3.5-zf-lab` 调试包沿用上一版的开发测试签名；签名文件不在仓库中。公开构建或发布应使用独立、稳定的发行签名。
